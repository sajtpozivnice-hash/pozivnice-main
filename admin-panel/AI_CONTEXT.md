# AI Context

This project is the internal administration panel.

Responsibilities:

- Manage clients
- Create projects
- Assign subdomains
- Manage authentication
- Send invitations
- Manage subscriptions
- Manage project ownership

This project does NOT contain the invitation editor.

Editor logic belongs to vencanja-main.

UniversalProjectConfig is created here but edited inside vencanja-main.

Use Supabase services for all database access.

Never duplicate logic that already exists in vencanja-main.
